# Paromita Datta Ray — Portfolio

Static, responsive academic portfolio for GitHub Pages. The CV PDF is intentionally excluded from Git by the `*.pdf` rule in `.gitignore`; keep the local copy in `resources/` if needed.

## Publish with GitHub Desktop

1. Review the changed files. Confirm the CV PDF does **not** appear in the Changes list.
2. Commit the portfolio files in GitHub Desktop with a message such as `Add academic portfolio`.
3. Push the commit to the GitHub repository.
4. In the repository on GitHub, open **Settings → Pages** and select the `main` branch and `/ (root)` as the source, unless Pages is already configured.

Because this repository is named `paromitadattaray.github.io`, the expected user-site address is `https://paromitadattaray.github.io/`. It becomes public after GitHub Pages is enabled and the pushed branch is deployed. If the repository owner differs, the address will use that owner's username.

The site links to public publication records and a public research profile. It does not display the CV's private email or phone details. Review the rendered page and paper metadata before publishing.
